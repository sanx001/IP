# 🌐 IPTrace — IP Address Locator

A responsive web application that retrieves and displays IP address information using API integration. IPTrace provides a simple and interactive interface for exploring IP-related information in a clear and user-friendly format.

## ✨ Features

* 🔍 Retrieve IP address information using an external API
* 📍 Display available IP-related location information
* 🌐 View network and geographical details returned by the API
* ⚡ Asynchronous API requests for dynamic data retrieval
* 🖥️ Responsive design for desktop, tablet, and mobile devices
* 🎨 Clean and interactive user interface
* 📊 Dynamically render API response data

## 🛠️ Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Application logic and dynamic rendering
* **REST API** — Retrieving IP-related information

## 🔄 How It Works

```text
Enter / Detect IP
       ↓
API Request
       ↓
Receive IP Information
       ↓
Process Response
       ↓
Display Information
```

The application sends an asynchronous request to the IP information API and processes the returned data using JavaScript. The relevant information is then dynamically displayed through the web interface.
